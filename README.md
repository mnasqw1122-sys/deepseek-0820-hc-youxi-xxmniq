# 太乙玄门 · 修仙模拟器

一个以**传统道家理念为核心机制**（而非仅作皮肤）的水墨风网页修仙模拟器。
零依赖、纯静态：`index.html` + `css/` + `js/`，双击即玩，无需构建、无需联网。

```
直接打开：  index.html
本地服务：  node tools/serve.js 8731   →  http://127.0.0.1:8731/
```

> `file://` 亦可运行（脚本皆为传统 script，无 ES 模块）；如浏览器限制本地存储，
> 请改用 `tools/serve.js` 以获得完整存档功能。

## 一、道家理念如何成为机制

本作的设计原则是：**每一条道家义理，都必须是一条会改变玩家决策的规则**。

| 道家理念 | 在游戏中的机制化 |
|---|---|
| **精气神三宝** | 三条独立资源池。精＝形体本元（亦为战斗生命），炁＝法力，神＝识海。 |
| **炼精化炁 · 炼炁化神 · 炼神还虚** | 三宝可依次相化，构成核心资源循环。「炼神还虚」直接把神魂换作道行，是高境界进境要门。每一节气内各可行一次，各耗时日。 |
| **五行相生相克** | 木生火→火生土→土生金→金生水→水生木；木克土→土克水→水克火→火克金→金克木。斗法伤害 ×1.45 / ×0.68；渡劫「引化」须以能克该劫之气应之；节气当令之气与本命灵根相生则修行倍速。 |
| **阴阳太极** | 阴阳值 −100…+100。`|阴阳| ≤ 15` 得「太极中和」加成；偏阳过甚则**走火**，偏阴过甚则**入魔**。节气会牵引阴阳（夏至极阳、冬至极阴），静坐与返虚可收摄归中——**顺天而调**是核心操作。 |
| **天干地支 · 二十四节气** | 一年 360 日 24 节气 60 甲子。每个节气有当令五行与阳气潮位，直接乘算修行效率。**择时而修**是第一等本事。 |
| **周易六十四卦** | 完整通行本 64 卦（卦名、彖辞、象辞、吉凶、动爻、变卦）。占卜设定本节气的气运乘数（×0.50…×1.60），影响修行、采药与奇遇分布。 |
| **善易者不卜 / 初筮告，再三渎** | 一节气内重复占卜：耗神翻倍、累积业障，且有概率「天不告」（卦象强制为「平」）。 |
| **经脉窍穴** | 十二正经 + 奇经八脉共 20 条。任督为诸经之先；通六正经方可开冲带，通八方可开维跷。**任督俱通即成小周天**（内景图动画流转）。 |
| **丹道君臣佐使** | 每张丹方有唯一君药，辅以臣、佐、使。 |
| **火候** | 炼丹时指针游走，于理想火位落指。误差决定丹品：废丹/下品/中品/上品/极品/仙品（药力 ×0…×3.10）。火系亲和、悟性、九转炉可放宽容差。 |
| **是药三分毒** | 同一丹连服逾三枚，药力按 0.82ⁿ 递减；逾六枚开始累积业障。 |
| **功德业障 · 承负** | 功德延寿、减劫、佑事；业障折寿、加劫（最多 ×2.2）、招灾。业障逾 150 者天劫中必现「业劫」；功德满 150 可化金甲替受一击。 |
| **上德不德** | 布施可换功德，然施之愈多所得愈薄（0.88ⁿ）——功德不可以钱买尽。 |
| **走火入魔** | 风险 = f(心法, 躁进, |阴阳|, 道心, 业障) − f(悟性, 功德)。六种偏差：走火、入魔、精散、神昏、道基裂、心魔现。 |
| **无为 / 躁则失君** | 六心法之中，**静坐**道行所得最微，却尽消躁进、复还道心、且**必不走火**。斗法中另有「无为」一项：不攻不守，回炁最多，且有几率令敌自乱。传说功法《无为真经》不造成任何伤害，纯以返照、涤除、闪避取胜。 |
| **企者不立，跨者不行** | 「强行冲关」可在道行不足时突破，代价是成算 −26%、业障骤积、失败则道行大损折寿。 |
| **一坐千年** | 深修一次所耗时日随境界暴涨：炼气 15 日 → 元婴 1 年 → 炼虚 10 年 → 大乘 100 年。故**高境界的真正敌人是时间**。 |
| **天劫九相** | 风、火、雷、水、金、心、业、寿、道。应对五法：硬抗、御宝、引化、顺受、遁避。 |
| **天道垂怜 · 知命** | 「顺受」使本劫加重 25%，却累积「天道垂怜」（每次 −17%，使后续诸劫皆轻），并增道心功德。通劫皆顺受另有重赏。 |
| **道劫天问** | 大乘以上，天劫末重必是天问（「何者为道？」「汝所求何物？」）。四答之高下本于《道德经》《南华经》，答语合于**道**者劫力 ×0.30，答「道即大力」者 ×2.20。 |
| **死生，命也** | 年岁至寿元则身死。境界、功德、悟性、经脉折为**传承**：下一世得赠悟性、灵石、寿元、道心、宿世丹方与一门「宿慧」法术，且更易得上品灵根。 |
| **天道恶盈** | 修行诸乘数以渐近曲线收束（上限 ×5.0）——「持而盈之，不如其已」。 |

### 境界九重

炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → **太乙玄仙**
（各分初期/中期/后期，共 27 阶；大境界突破须渡天劫）

三大阶段依丹道：**炼精化炁**（炼气、筑基）→ **炼炁化神**（金丹、元婴）→ **炼神还虚 / 虚极返道**（化神以上）。

## 三、美术

全部**程序化生成**，无任何外部图片/字体资源。

- **人物立绘**（Canvas，`js/avatar.js`）：左栏「神形卷」中，修士盘坐结印，随境界演变——
  炼气筑基仅丹田微芒；**金丹**现丹光；**元婴**顶上坐婴；**化神**显法身重影、眉心现印；
  **炼虚**身透如虚；**合体**五气环身；**大乘**悬宝光轮；**渡劫**顶雷冠；**飞升**化金身白芒。
  衣袍随本命五行着色，气轮随阴阳偏性转红转青，真炁灵纹绕身升腾，伤重则血痕斑驳、躁动则气乱，
  心魔/躁动/阴阳偏颇皆有角标。战斗中立姿对峙，受击抖动、施法放光。
- **妖魔立绘**：六类各具其形——妖兽四足走兽、魔物双角獠牙、幽魂下身化雾目放幽光、
  修士持敌意衣色、精怪灵核花触、龙属蜿蜒吐须；魁首外罩赤环。
- **水墨山水背景**（Canvas）：五层程序化山脊（多重正弦 + fBm 抖动）、层间云气留白、皴笔、
  随节气移位的日月与月相、飘移雾带、水面波光、程序化松枝竹石前景。
  13 个地域各有独立配色，24 节气各有天色与粒子（春落花瓣 / 夏升火星 / 秋飘黄叶 / 冬降飞雪 / 长夏浮尘）。
- **纪事界面**：高度可拖拽调节（底部把手），条目带**类别方章**（修/战/丹/卜/劫/游/行/炼），
  叙事条用楷体缩进，大事居中朱书——不再是一墙纯文字。
- **太极图**（Canvas）：持续旋转，阴阳鱼比例实时反映玩家阴阳值；中和时泛金晕；外套八卦环。
- **五行生克图**（Canvas）：外五边形绿箭为相生，内五角红虚线为相克；节点半径与辉光随亲和度变化。
- **经脉内景图**（SVG）：侧身打坐人形，20 处窍穴随贯通而亮起；任督俱通则小周天路线流转。
- **丹炉**（Canvas）：三足饕餮纹鼎、随火候变色的炉焰、上升火星、丹光。
- **天劫**（Canvas）：递归分叉雷电 + 屏闪 + 劫云暗罩；突破时金色扩散光环。
- **宣纸质感**：SVG `feTurbulence` 噪声 + 多层径向渐变 + `mix-blend-mode: multiply`。
- 朱砂印章、竖排标题、笔触分隔线、卷轴角饰、飘字数值。

### `audit.js` 验什么——`verify.js` 验不到的那些

`verify.js` 只验**结构契约**（id 是否存在、数值是否越界、白名单是否吻合）。
这些全过了，游戏照样可能是错的。`audit.js` 验**内容是否正确、是否可玩**：

| 类别 | 检验项 |
|---|---|
| **六十四卦数理** | 卦名与通行本卦序逐一比对；64 组爻画穷尽且互不重复；**爻画 = 下卦三爻 + 上卦三爻**；卦名全称 = 上卦之象 + 下卦之象 + 卦名；**32 对卦皆成「反卦」或「错卦」之偶**（通行本卦序的数理指纹）；自反之卦恰为乾坤颐大过坎离中孚小过 |
| **八卦表** | 爻画、Unicode 卦符、五行、卦象、后天方位逐一比对定说 |
| **辞与吉凶** | 彖辞/象辞/指引无重复；名篇辞句合于原文；吉凶不违传统认知；吉凶乘数单调 |
| **文本卫生** | BOM、编码损坏、**繁体字泄漏**、占位符、网文/系统流腔（仅扫玩家可见文本，不误判代码标识符）、无实义字段、半角引号 |
| **数值单调性** | 法术威能/耗炁、法宝属性和、灵药药力、丹药药效、火候容差，皆须随品阶单调；性价比离群检测（2.6σ） |
| **自洽性** | 法术类别与效果相符（攻伐必有伤、疗伤必有回、神魂必伤神）；妖魔法术与其五行相契；《无为真经》须无直伤 |
| **可炼性** | 每味灵药皆有可采之地；每张丹方之药材在其标称境界即可得；开局丹方须当即可炼；君臣佐使配伍 |
| **可战性** | 妖魔归一化后**是否付得起自己的法术**、能否持续施法；各境界妖魔攻/精须在同级修士 0.45–1.9 倍；魁首须够格 |
| **可达性** | 事件条件是否自相矛盾或永不可达（`loc` 与 `features` 冲突、`needFlag` 无人授予、地域门槛高于 `realmMax`）；各境界可遇事件数；妖魔/灵药是否成孤儿 |
| **检定校准** | 以**疏 / 常 / 精**三等修士分别试全部检定：寻常者不可必成、精修者不可必败、成算须随投入单调上升 |
| **抉择张力** | 每桩奇遇须含代价、检定或负面后果；因果类须有功德或业障之实报；重宝须计入地域门槛后仍有境界要求 |
| **端到端实跑** | 62 法术 × 44 妖魔全组合施放 + 妖魔反击；26 丹方 × 3 种火候开炉；60 奇遇 × 全部 180 选项解算；检查非数与寿元归零 |

#### 此番审计实际揪出的问题

- **5 桩奇遇永不可达**：`cond.features` 与所限地域的机能冲突（埋骨、剑冢、坐化洞、地火喷发、雪崩）。
  其中「坐化洞」是《无为真经》**唯一**的奇遇来源——招牌功法本来根本拿不到。
- **3 味顶阶灵药无处可采**：产地为天柱峰／太虚观，而二者当时皆无 `gather`，
  致九转金丹等顶级丹方只能靠买。
- **检定刻度全盘错位**（引擎侧，我的锅）：`checkStat` 返回值与图籍所用 dc（13–20）不在同一量纲，
  致气运／神魂／道心类检定**几乎必成**，法力类在低境界**必不成**——44 处检定的设计意图被静默抹平。
  重校后：疏于此道 34% / 寻常 57% / 精修 96%。
- **传说功法可在炼气期施展**：`techList` 未校验 `t.realm`，早期白得的五阶功法可直接开大。
- **顶级法宝可在炼气期白得**：「灵兽献宝」无境界门槛，且「纳宝入怀」零代价即赠太极图，
  同时使慈悲之选被严格支配。已改为门槛元婴 +「取而不顾其伤」得业障、「先疗其伤」得功德与延寿。
- 三处地域配色过近、`清心咒` 类别标错、24 处半角引号。
